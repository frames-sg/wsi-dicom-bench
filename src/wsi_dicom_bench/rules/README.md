# WSI-DICOM rule catalogs

The package includes the current v5 core challenge catalog and v3 core profile, the
frozen v4 catalog and v2 profile that earlier studies pin, and the v2 general catalog
used by converter format-coverage runs. Catalog v5 adds the VL WSI IOD requirement
families of `wsi-dicom` rule sets `wsi-dicom-general-v2` and
`wsi-dicom-core-profile-2026c-v3`. Their identifiers
are stable provenance fields. The grouped profile rows do not claim exhaustive DICOM
coverage.
