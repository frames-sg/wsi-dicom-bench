# WSI-DICOM Negative Bench package template

The generator fills the package title, case/control counts, catalog identity and commands from
the selected locked manifest. It copies the protocol, expected results, controls, mutation runtime,
and analysis code needed for reproduction. See the [workbench guide](../../../docs/WORKBENCH.md)
for current inputs and commands.

This template does not establish a published release or archival DOI. A completed package must
pass the evidence gate and be sealed before publication review. Never edit a sealed package.
